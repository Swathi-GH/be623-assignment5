This document contains the information regarding all the files present in this repository.

1) be623_A5.R: R-script containing the code for analysing circadian gene expression (for the genes PER2 and BMAL1) and generating plots.
2) circadian_expression.csv: CSV file containing circadian gene expression data for PER2 and BMAL1 genes
3) rhythm_plot.png - Scatter plot for visualizing the circadian expression patterns with respect to time (hours) of PER2 and BMAL1.
4) expression_boxplot.png: Boxplot comparing the expression distributions of PER2 and BMAL1.
5) .gitignore: Contains Rstudio generated files and directories that Git should ignore.
6) README.md: Describes the files and the content in the repo.
